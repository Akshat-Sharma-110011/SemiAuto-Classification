Processing Mode Guide

Auto-detect

Automatically analyzes your data characteristics and selects the most appropriate processing mode.

Tabular

For structured data with numerical and categorical columns. Best for traditional ML tasks like regression and classification on structured features.

Textual

For text-heavy datasets suitable for NLP tasks. Focuses on text analysis, feature extraction from text, and text classification.

Image

For computer vision tasks with image data. Upload a zip file of images and a CSV file containing image filenames with their labels for classification.

Mixed

For datasets containing both structured features and significant text content. Combines tabular and textual processing approaches.

Image Data Format Requirements

For Image Classification:

  1. Images Zip File: A zip file containing all your image files (JPG, PNG, BMP, TIFF, GIF formats supported)
  2. Labels CSV File: A CSV file with at least two columns:
    • One column containing image filenames (e.g., "image1.jpg", "photo_001.png")
    • One column containing class labels (e.g., "cat", "dog", "airplane")
Example Labels CSV:
filename label
cat_001.jpg cat
dog_001.jpg dog
airplane_001.png airplane
Note: The system will automatically detect which column contains filenames and which contains labels. Make sure all image filenames in the CSV exist in your zip file.
